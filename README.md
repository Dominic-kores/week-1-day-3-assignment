# CSS Layout Mastery Assignment

This project contains three CSS layout exercises completed as part of my web development learning.

The purpose of the project is to practise three important CSS concepts:

1. Flexbox
2. CSS Grid
3. Sticky positioning and page navigation

Each task is contained in its own HTML and a shared CSS file.
